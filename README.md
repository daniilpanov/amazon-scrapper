# AmaScrap3
Это проект, предназначенный для сбора информации о продуктах с сайта Amazon.com

В версии 3 присутствуют существенные нововведения, такие как:
- сбор брэндов продуктов по запросу
- сбор продуктов по запросу (используя раздельный сбор по брэндам или быстрый сбор)
- сбор детальной информации по каждому продукту
- сбор отзывов по каждому продукту

Кроме того, теперь сбор проходит в несколько потоков, что позволяет ускорить процесс сбора данных в несколько раз
